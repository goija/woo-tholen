4. De 5-Lagen Technologische Stack & Geodetisch Rekencentrum

                    
Bare-metal Debian Linux t/m MapLibre GL JS en interactieve WASM/Rust/R rekenkernen.

                


                
                

                    

                        
Laag 5 — Applicatie, GIS & Solid Pod Viewports

                        
HTML5, CSS3, ES6+, MapLibre GL JS (3D-globe & DXF), Solid Pod HTML Bouwer & Viewer (`01-home` t/m `08-bibliotheek`).

                    

                    

                        
Laag 4 — Transport, Backend, WASM & P2P

                        
Python 3.11+ REST API (RFC 9110), WebAssembly Core 2.0 bridges en WebRTC/DTLS (RFC 8825–8832) voor lokale P2P synchronisatie.

                    

                    

                        
Laag 3 — Netwerk, BIND9 DNS & Matrix Signaling

                        
Geïsoleerde BIND9 DNS (`home.arpa` RFC 8375, DNSSEC RFC 4033–4035) en Matrix homeserver (Conduit / Continuwuity / Tuwunel v1.18/v1.19).

                    

                    

                        
Laag 2 — Security, Datalink & WAC

                        
FinalCrypt (OTP) at-rest, W3C Web Access Control (`.acl`), DTLS 1.3 (RFC 9147) en herziene TLS 1.3 (RFC 9846, juli 2026) in-transit.

                    

                    

                        
Laag 1 — Fysiek & Bare-Metal OS

                        
Debian 12.15 Bookworm LTS (tot 30 juni 2028) → Debian 13.6 Trixie op eigen x86_64 / ARM64 hardware (Zero-Cloud).
